# ael

Adaptive Extensible Lisp [UNVERSIONED]

(Or... All-Encompassing Lisp for the true believers!)

I plan to make:
1) System programming-oriented GC-less static Lisp for low-level things, memory-efficient and so on. ael-sys?
2) General-purpose feature-filled Lisp with GC, written entirely in ael-sys. Named, well, ael

- ael-sys will be initially transpiled into C99 (custom machine-code generator in future)
- ael and ael-sys having common subset (syntax + semantics) is probably a good idea too
- homoiconicity, REPL-oriented dev, godly macros, reflection - FTW

All in all, **WIP**
